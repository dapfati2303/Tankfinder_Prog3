# Tankfinder_Prog3
Entwicklung einer benutzerfreundlichen, datengetriebenen Web-Applikation auf Basis von Python und Streamlit, die es Autofahrern ermöglicht, aktuelle Kraftstoffpreise (Super E10, Super E5, Diesel) verschiedener Tankstellen in einer definierten Region transparent zu vergleichen.

Die Anwendung soll folgende Kernfunktionen bieten:
- Echtzeit-Datenintegration: Abruf und Aufbereitung aktueller Preis- und Stammdaten von Tankstellen (z. B. über Schnittstellen oder strukturierte Datenquellen).
- Interaktive Kartendarstellung: Visuelle Darstellung der Tankstellenstandorte mit automatischer Markierung der günstigsten Optionen in der Umgebung.
- Intelligente Filter- und Suchfunktionen: Sortierung und Filterung nach Kraftstoffart, maximalem Preis und Entfernung.
- Preisanalyse & Verlauf: Übersichtliche Statistiken und Preistrends zur Ermittlung des optimalen Tankzeitpunkts.
