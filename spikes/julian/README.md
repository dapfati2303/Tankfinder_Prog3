# Tankfinder
Tankfinder ist eine moderne Webanwendung, die entwickelt wurde, um Nutzern die effiziente Suche nach Tankstellen zu erleichtern—Basierend auf lokalen Daten bietet die Anwendung intuitive Filter- und Suchoptionen.

# Funktionen
Durchschnittspreisberechnung: Ermittelt den mittleren Kraftstoffpreis für verschiedene Marken.

Markenfilter: Ermöglicht die gezielte Anzeige von Tankstellen bestimmter Anbieter.

Preislimit-Suche: Filtert Stationen basierend auf einem maximalen Preis.

# Projektstruktur
app.py: Hauptdatei zur Steuerung der Streamlit-Benutzeroberfläche.

daten.py: Enthält die Stammdaten und Beispielinformationen zu den Tankstellen.

funktionen.py: Implementiert die Logik und Algorithmen—Einschließlich Filter- und Berechnungsfunktionen.
